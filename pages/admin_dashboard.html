注册与安全
Turnstile 人机验证

在 Cloudflare 控制台获取 Site Key 与 Secret Key。填入并保存后，登录、注册等场景即按下方开关启用验证。Secret Key 仅保存在服务端，绝不会下发给浏览器。

仅在需要更换时填写；保存时留空则不修改已存储的 Secret。
OAuth 凭证（GitHub / Discord / Cloudflare）

在此填入各平台的 Client ID 与 Client Secret，保存后立即生效，无需改代码或重新部署。未填写的字段会自动回落到 Worker 环境变量。Secret 仅保存在服务端，绝不会下发给浏览器。

Cloudflare 绑定（数据主权）

用于用户「绑定自己的 Cloudflare 账号」：授权后系统会在用户自有 CF 账号下自动创建 KV + D1 存储，文件与数据归用户所有。需在 Cloudflare Dashboard → My Account → API Tokens → OAuth Applications 注册一个应用。

  • 回调地址（Redirect URI）：https://api.example.com/api/cf/bind/callback
  • 所需 Scope：account:read · workers_kv_storage:edit · d1:edit

意见反馈弹窗（用户侧）

点击导航栏「意见反馈」后弹出。正文支持 Markdown，由超级管理员编写；可引导用户私信官方账号主页或发邮件到下方邮箱。

弹窗里「前往官方主页」会跳到 /user.html?u=这个用户名。
弹窗里会显示「发邮件」按钮（mailto:）。
支持标题、列表、加粗、**代码**、`行内代码`、链接等。
邮件服务（发件配置）

用于发送注册 / 登录 / 重置密码验证码。填写并保存后立即生效，无需改代码或重新部署。推荐 Resend（需先在 Resend 验证你的发件域名）。

⚠️ 必须是 已在 Resend 验证 的发件域名（如 no-reply@example.com）。未验证的域名 Resend 会拒绝发送（422）。不确定时先用 Resend 官方测试地址 onboarding@resend.dev 验证通道是否通。
仅保存在服务端，不会下发给浏览器。Resend 的 Key 形如 re_xxxx。
浏览器推送（VAPID）

首次开启推送前，需要生成 VAPID 密钥对。公钥会下发给浏览器用于订阅，私钥仅保存在服务端 KV，不会泄露。轮换密钥会清空已有订阅。
